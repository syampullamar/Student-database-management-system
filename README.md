# Student-Data-Management-using-Linked-List-Data-Structure

## Overview
This mini-project is developed in C using a Singly Linked List. It manages student records efficiently using dynamic memory allocation and file handling.

## Features
- Add Student
- Delete Student
- Modify Student
- Display Students
- Sort Students
- Reverse Linked List
- Save Data into File
- Delete All Records

## Technologies Used
- C Programming
- Singly Linked List
- Dynamic Memory Allocation
- File Handling
- Modular Programming
- Makefile

## Project Structure
```text
main.c
header.h
stud_add.c
stud_del.c
stud_mod.c
stud_show.c
stud_save.c
sort_list.c
reverse_links.c
del_all.c
Makefile
```
## How to compile 
```bash
  make
```
 ## How to run 
 ```bash
 ./final
```
